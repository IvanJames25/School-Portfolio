# 👥 Team Project – TEAM ADL

![Team ADL](TeamADL.png)

### TEAM ADL – Avila • Dorado • Langres

**CYFER** is a **secure password manager** designed to help users safely store and manage credentials.

### Key Features

• Secure encrypted password vault  
• Intuitive and user-friendly interface  
• Credential storage and management  
• Cross-device synchronization  

The goal of CYFER is to provide a **safe and efficient way for users to store and manage their digital credentials.**

# 📖 Usage Instructions

## 🔐 User Authentication
A. Login to CYFER vault  
B. Enable multi-factor authentication (optional)

## 🔑 Password Management
A. Add new credentials (username, password, URL)  
B. Edit existing credentials  
C. Delete credentials  

## 📂 Organizing Credentials
A. Create categories or folders  
B. Move credentials between folders  

## 🔍 Password Retrieval
A. Search credentials by keyword or category  
B. Copy or auto-fill passwords  

## 🔄 Synchronization
A. Sync vault data across devices  

## ⚙️ Settings and Security
A. Change master password  
B. Enable biometric authentication  
C. Configure synchronization preferences
